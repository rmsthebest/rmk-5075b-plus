# firmware

The images for the Akko 5075B Plus. `akko-rmk` is the keyboard firmware; the others are the
bring-up milestones, kept because the sim suites test them.

| Bin | What it is |
|---|---|
| `akko-rmk` (`src/main.rs`) | RMK with Vial: matrix scan, knob, lighting, USB, BT/2.4G radio, sleep/stop, watchdog |
| `m1a-bounce` | Boot-guard only, with `--features always-dfu`: re-enters DFU at every boot |
| `m1b-stub` | Boot-guard, then blinks Caps Lock (raw registers) and returns to DFU |
| `m2-blink` | HAL test: 1 Hz blink on embassy-time, Esc via EXTI goes to DFU |
| `m3-usb` | USB test: CDC log + HID keyboard on test VID:PID 1209:0001 |

## Modules of `akko-rmk`

| Module | Purpose |
|---|---|
| `main.rs` | wiring, RAM placement (`.ram2`), storage windows on the SPI flash |
| `scan.rs` | matrix scan (QMK-style columns), the Win/Mac switch, diagnostics |
| `knob.rs` | encoder on B7/B6, QMK's quadrature decoding |
| `keymap.rs` | default keymap, generated from the QMK VIA keymap (`tools/gen_keymap.py`) |
| `lighting.rs` | `akko-lighting` on the 106 WS2812 LEDs, VialRGB, the settings record |
| `radio.rs` | `qmk-wireless` on UART3: device keys, report hook, Vial stats |
| `power.rs` | sleep timeout and light sleep |
| `stop.rs` | stop mode's wake lines, around `wb32_hal::stop` |
| `watchdog.rs` | software watchdog on the TIM2 tick |
| `bootloader.rs` | QK_BOOT straight into DFU |

`rmk.toml` is RMK's keyboard config, `vial.json` is the Vial definition (generated by
`tools/via2vial.py`), and `memory.x` is the layout that `akko-boot-guard` and `tools/precheck.py`
expect.
